# Bio Challenges

A community-maintained calendar of biology competitions and benchmarks. Each folder in [competitions](competitions) contains an organizer reference, participation information, and links to published results when available.

MoleculeDesk reads this catalog to build its [competitions pages](https://moleculedesk.com/competitions). The site includes upcoming deadlines, past competitions, and ongoing benchmarks.
